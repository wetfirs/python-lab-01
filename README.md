# Toolkit: калькулятор и конвертер величин

Консольное приложение на Python, включающее калькулятор арифметических выражений и конвертер единиц измерения.

Калькулятор использует токенизацию, валидацию, преобразование выражения в постфиксную запись (RPN) и вычисление через стек.

## Возможности

### Калькулятор

Поддерживаются:

- `+`, `-`, `*`, `/`
- `//`, `%`
- унарные `+` и `-`
- скобки
- целые и дробные числа
- приоритет операций
- отрицательные операнды

Вычисления выполняются через `Decimal`.

Результат округляется до 10 знаков после запятой по правилу `ROUND_HALF_UP`.

Пример:

```bash
python -m toolkit calc "2+3*4"
```

### Конвертер

Поддерживаются:

- длина: `mm`, `cm`, `m`, `km`
- масса: `g`, `kg`
- температура: `c`, `f`, `k`

Регистр единиц измерения не учитывается.

Преобразование между несовместимыми группами запрещено.

Пример:

```bash
python -m toolkit convert 1000 --from mm --to m
```

## Основные функции

### calculator.py

- `tokenize` — разбивает выражение на токены
- `is_number` — проверяет, является ли токен числом
- `validate` — проверяет корректность выражения
- `to_postfix` — преобразует выражение в RPN
- `calculate_postfix` — вычисляет выражение через стек
- `calculate` — выполняет полный цикл вычисления

### converter.py

- `convert_temperature` — преобразует температуру
- `convert` — преобразует единицы измерения

### __main__.py

- `main` — обработка аргументов командной строки
